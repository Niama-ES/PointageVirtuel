## 🦋 Overview

**Pointage Virtuel** is a web-based employee attendance management system developed during an internship at **Eurafric Maroc**.

The project aims to digitize employee time-tracking operations through a centralized platform, providing a structured way to record and retrieve attendance entries.

Built with Spring Boot and React.js, the application follows a client-server architecture and communicates through RESTful APIs.

## 🦋 Key Features

- **Digital Attendance Recording:** Manage employee check-in and check-out entries.
- **Dynamic Forms:** Form-driven interfaces for recording attendance information.
- **REST API Integration:** Dedicated endpoints for creating and retrieving attendance records.
- **Employee Tracking:** Retrieve the latest attendance entry using an employee identifier.
- **Backend Architecture:** Structured backend implementation using Spring Boot.
- **Technical Documentation:** Documentation covering the system architecture and implemented functionalities.

## 🦋 System Workflow

1. **Interact** — Employees or authorized users access the attendance interface.
2. **Submit** — Attendance entries are submitted through dynamic forms.
3. **Process** — The Spring Boot backend validates and processes incoming requests.
4. **Store** — Attendance records are persisted in the database.
5. **Retrieve** — REST API endpoints provide access to the latest attendance information.
